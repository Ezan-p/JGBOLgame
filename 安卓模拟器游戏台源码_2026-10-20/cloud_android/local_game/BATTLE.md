# 金箍棒战斗机制完整文档 · local-v4

本文件对应可运行的 `combat.py`、`battle_rules.py`、`battle_training.py`、`battle_modes.py` 和原生 Lua 播放器。上一版 BATTLE.md 所列的基础战斗、38 项特技、大乘经、觉醒、进阶、助阵法术、分步入场及各模式的本地替代版均已接入；另补充了本轮新发现的 75 项觉醒星宿。

## 1. 证据等级与适用范围

- **【原版确认 A】**：原客户端 Lua 中可直接看到的行为、字段、资源或 CSV 数字。确认客户端怎么显示，不自动等于确认服务器怎么计算。
- **【推测规则 B】**：缺少服务器表达式或事件优先级时，依据客户端字段、描述设计并已应用的计算规则。
- **【本地规则 C】**：为离线可玩而明确新增的获取、门槛、匹配、奖励及限制，不声称原服如此。

当前版本为独立本机游戏，未连接原服。没有恢复原服账号、跨服网络、真人排行榜和仙盟组织服务；竞技及仙盟采用可实际挑战的本地对手／首领。这属于服务替代，不是假称恢复了在线系统。

本轮新增快照读取原版已安装客户端的 `release_w` 更新资源，版本 1263。`local_game/battle_resources/manifest.json` 保存每个资源的文件名、字节数、SHA-256；原始渠道包不被修改。完整配置及来源见 `outputs/battle-v4-20261021/战斗逆向与规则数据.json`（导出文档的同目录）。`scripts/export_battle_manual.py` 可重建本文。

## 3. 战前属性与装备来源

四维：生命 H、攻击 A、守御 D、法力 M。法力在本地是法术强度属性，不作为每次施法消耗的蓝量；客户端战场没有提供足够证据恢复耗蓝／回蓝系统。

【B】常规属性顺序：

1. 沿用本地角色成长 `基础值 × (1 + .14 × (角色等级−1))`，当前培养上限 20（C）。原版 NPC 读取原关卡指定等级及 `base_* + base_*_plus × (等级−1)`（读取字段为 A，成长解释为 B）。
2. 加装备和灵石得到的固定值，加觉醒方向固定值，加星宿固定值。
3. 同属性被动法术、星宿百分比、法术进阶生命百分比相加，作用于第 2 步结果。
4. 继续应用已实现的仙缘加成，再计算非递归的八卦助阵转移。
5. 战斗入场后处理强壮、祝福等临时属性；这些不反写培养存档。

`battle_stats_ready` 防止 UI 已计算的被动在战斗再次增加。`_base` 固定为战前最终四维；本地特技描述中的“基础攻击／防御／生命”均引用它，而不是随临时效果滚动放大（B）。祝福、战意按 `_base` 增量相加，避免复利失控。

## 4. 八阵位、先手、目标与回合

【A】每方 8 个战斗位置，1–4 首发，5–8 后备。1→5、2→6、3→7、4→8；对应后备不存在时不借用其他后备。后备未进场前不攻击、不被群攻或治疗选中。原版总血槽包含后备。

【A】死亡播放 `106_1.ccbi`；复活先登记到 `g_fight_events_revive`，成功时不补位。补位延迟 .6 秒，以 .4 秒从斜上方落场，读取 `v2/enterSence.png` 和 `105_1.ccbi`。角色坐标与遮挡层沿用原版。完整动画采用本地时间轴，不承诺逐帧相同。

【B】每轮按位置交替行动：先手第1位、后手第1位、先手第2位……；轮初确定行动名单。行动中补上的角色从下一轮行动，死亡角色从名单跳过。普通 PvE 我方先手；竞技比较队伍法力总和，持平我方先手。`first_hand` 字段存在为 A，比较规则为 B。

【B】单体优先当前仍在场的最低原阵位号；群攻取全部场上存活者。没有捏造全体都带闪避、嘲讽或速度属性。前排为空而后备存在时在开场安排后备入场。全队无场上单位但有未来 `step` 援军时推进到下一有效入场步骤，避免提前判负。

【A/B】`step` 对应原客户端非被动攻击步骤计数；本地每个主行动后增加一次，附加攻击与状态事件不增加。剧情演武安排 step=6 的援军与一次指定复活，是本地剧情配置 C，并非声称复用了所有原剧情。

【C】最多 30 轮。仅一方有生还者则胜／负；双方都活着到上限或同时无生还者为平局。结算不把平局当胜利。

## 5. 完整伤害计算管线（B，除明确注明处）

定义 `R(x)=floor(x+0.5)`；生命、伤害非负整数。已有培养／仙缘模块沿用其原取整规则，战斗新公式统一使用 R。

### 5.1 普攻与法术基值

- 威慑存在时 `A_eff = A × (1−威慑比例)`。
- 法术基础威力 `I = 表基础威力 + upgrade_plus × (法术等级−1)`；等级限制在原表上限内（字段 A）。
- 原生法术觉醒：`I ← I × (1 + awaken_skill_rate / 100)`（显示表达式 A）。
- 星宿法强：`I_eff = I × (1 + 法强百分比) + 法强固定值`（叠加顺序 B）。
- 普攻 `P = max(0,A_eff)`，`E = max(0,D_target)`。
- 法术 `P = max(0,A_eff) + max(0,M) × max(0,I_eff)/100`，`E = max(0,D_target) + .25 × max(0,M_target)`。
- `基础伤害 = max(1, R(P² / max(1,P+E)))`。

选择该式的理由：同配置提高攻击／法力不会降低伤害，提高守御／目标法力不会增加伤害；防御连续生效，不会出现旧减法公式的负伤害与大范围硬卡 1；高攻仍有收益。`.25` 是平衡假设，没有伪称原服常数。

单体与群体使用各自原表威力。群攻对每个在场目标独立计算，不再人为加“首目标完整、其他 .55”衰减，也不再套固定 1.45 大招倍率。原表群攻威力通常比单体低，已经形成基础差异。

### 5.2 暴击、格挡、法抗与强袭

【A】觉醒星宿明确区分普通攻击暴击、暴击伤害、抗暴率及暴击减伤。没有相关星宿时本地默认暴击率为 0，不无条件给角色加暴击。

【B】普通伤害及其附加普攻：`暴击概率 = clamp(暴击率−目标抗暴率,0,1)`；成功后乘 `max(1,1.5 + 暴击伤害加成−目标暴击减伤)`。1.5 的基础倍率是推测。法术、毒伤、分摊不会重新抽暴击。

【A】格挡只针对普攻；法抗针对法术；法穿降低法抗减免效果。实际比例取特技表。

【B】格挡成功按表比例乘 `(1−格挡减伤)`；法抗伤害乘 `1−法抗比例×(1−施法者法穿比例)`。连击／反击先乘附加攻击倍率，再进行该次防御判定。

【A/B】强袭仅主普攻触发，额外伤害取未暴击的普攻基值 × 强袭比例；持有威慑的防守者按表降低强袭额外伤害；攻击者持有招架且目标持有反击时，按表提升这部分额外伤害。该部分在暴击、格挡后相加，具体顺序为 B。

### 5.3 幸运、护盾、分摊、免死、复活

1. 对斩杀附加攻击，若预计致死，幸运按原表概率将该次伤害置 0（A 描述；判定点 B）。不是对所有致死攻击都闪避。
2. 目标护盾先吸收；剩余伤害才进入大乘经分摊。
3. 存活、已入场的其他大乘经持有者按吸收率分摊；总分摊最多 60%，多个持有者按比例归一，不能循环互相分摊。
4. 分摊到守护者的伤害可被其自己的护盾吸收，不再次计算防御、不再次转移。
5. 真正扣血前，觉醒星宿免死成功时保留 1 生命，消耗本场次数；这是免死而不是复活。概率与次数来自星宿表，保留 1 生命为 B。
6. 扣血最多扣至 0。一次群攻所有命中结算后统一检查复活；复活成功清除毒、威慑与破甲，恢复配置比例生命。失败才安排对应后备。

护盾不增加最大生命。免死可以被毒伤检验，幸运只保护斩杀；二者适用范围由本地一致规则明确区分。毒伤不触发大乘经分摊、反击或吸血，仍可消耗已有护盾和检验免死／复活。

### 5.4 回血与伤害守恒

吸血以主目标实际生命损失为基数，排除护盾吸收及转移给守护者的部分，不因溢出伤害回血。连击／斩杀可以吸血，反击不再触发吸血（后者为防递归的 B）。所有治疗不超过最大生命，普通治疗不复活。

内部治疗技能 6：`R(.8×攻击 + 法力×法术威力/100)`，仅己方在场存活受伤者；无人受伤则普攻。这是 B；原表该引导技能概率为 0，正常装备不会凭空自发施放。

毒伤按施毒方计入累计伤害，即使施毒者后来阵亡也保留归属；首领奖励据实际生命损失统计。

每个命中保存 `damage/hp/max_hp/shield/absorbed`，直接伤害另保存公式输入与中间值。`damage` 只代表实际生命变动，治疗／复活为负值；状态提升生命上限通过独立 `changes` 记录，不伪装成受到伤害。

## 6. 法术触发与公式编号

【A】`use_mode` 区分主动／被动；`effect_target` 区分单体／群体；正常单体通常 15%，群体通常 10%，逐项以附录表为准。第1槽原生法术，第2、3槽额外法术；同名法术不能重复装配。

【B】每次主行动按槽1→2→3排列互斥概率区间抽一次，剩余概率普攻；若总概率超过100%，按比例归一。法穿对正常非零概率法术增加1个百分点（基础特技）／2个百分点（高阶特技）；原文只说“少量提升／提升”，具体数字为 B。

## 7. 特技事件顺序与所有19类效果

【A】38 项特技分基础101xx、高阶102xx，每项5级。旧 `skill_ext_name` 的401系列不能直接当作更新后道具名称：例如当前10104/10204叫招架，10115/10215叫斩杀，旧路由函数名仍可能叫反击无效／不倒。

【B】入场：强壮 → 祝福。每轮开始：解毒 → 各层毒伤与过期 → 死亡／复活／补位 → 第二轮起愈合。每个主行动：每两次自身主行动的战意 → 法术抽签 → 主攻击／群攻 → 死亡处理 → 吸血 → 被攻击者的大乘经护盾 → 威慑／破甲／中毒 → 反击或招架 → 连击，否则检查斩杀。

反击、连击、斩杀都是终止生成攻击链的附加攻击，不再触发新的反击、连击、斩杀或攻击型负面状态。仍能被格挡、法抗、护盾、分摊、免死、复活处理。此限制为 B，避免双反击或双连击无限循环。反击成功杀死原攻击者会中止其后续附加攻击。

| 类别 | 原版描述确认 A | 实现补充 B |
|---|---|---|
| 威慑 | 攻击概率降低对方下次攻击力；自身减轻强袭 | 同时存在取较强值，下一次攻击后清除 |
| 破甲 | 攻击概率降低对方基础防御，直到阵亡 | 同次来源可叠加，最多降低基础防御90%；保留祝福额外防御 |
| 反击 | 被攻击概率反击，按普攻比例 | 单次群攻各存活目标可独立反击，不递归 |
| 招架 | 使反击无效；强化对反击者的强袭 | 先判反击成功，再判招架，未触发反击不白抽招架 |
| 嗜血 | 将对手生命损失转为自身生命 | 只按实际主目标扣血计算 |
| 格挡 | 普攻概率减伤 | 不对法术、毒伤、分摊重复判定 |
| 连击 | 概率追加一次按比例普攻 | 成功时不再斩杀，也不无限连击 |
| 法抗 | 减少法术伤害 | 按比例作用于法术基值 |
| 法穿 | 降低法抗效果，提高施法概率 | 减免乘法抵消；概率提升1/2个百分点 |
| 愈合 | 第二回合起概率回复基础生命 | 解毒／毒伤之后执行；幸运放大回血量 |
| 强袭 | 普攻概率额外伤害 | 暴击／格挡后添加独立额外部分 |
| 战意 | 每两回合提升基础攻击 | 按该神仙实际主行动次数，每两次增量一次 |
| 强壮 | 出场提升生命上限 | 同时增加当前生命，仅首次入场触发 |
| 幸运 | 提升愈合；被斩杀时概率躲避 | 仅斩杀附加攻击的致死检查 |
| 斩杀 | 对手低于阈值时概率再攻击，连击时无效 | 使用一次普通攻击基值，不能再触发追击 |
| 中毒 | 回合开始扣基础生命，单次最多20万，持续3回合，可叠加 | 每层独立计3次，轮首新层下一轮才结算 |

## 8. 大乘经：已确认部分与推测部分

【A】更新后的 `skillUpgradeUI.lua` 显示表达式：

- 未觉醒吸收百分比 = `rulai_skill_base.absorb_rate + 当前法力 / 800`。
- 觉醒吸收百分比 = `absorb_rate × 1.1 + 当前法力 / 800`。
- 盾率显示值 = `shield_rate`；觉醒再乘 `1 + awaken_skill_rate[21]/100`。

【B】本地把盾率解释为受到直接攻击后生成护盾的概率。护盾给己方当前生命比例最低的存活在场神仙，持有者每次增加 `R(自身法力×.15)` 护盾，上限受益者最大生命的50%；相同目标取累加至上限。`.15`、上限、按比例选最低及触发优先级均为推测，不能写成原版已确认。

【B】吸收率单人上限60%，多人总上限60%。例如法力800、一级大乘经，吸收率=(3+1)%=4%；目标剩余900伤害，两位4%守护者各分摊36，目标承担828。守护者可以因分摊阵亡并正常检查复活／后备。

## 9. 原生法术成长、觉醒、进阶、助阵与星宿

### 9.1 原生法术与觉醒

【A】原版觉醒检查 `protogenic==1`、`equip_pos==1`、法术等级满足表值、`reborn_layer>0`，仅原生法术。方向1攻击+1500、方向2守御+1000、方向3法力+800，材料与法术效果提升比例读取原表。

【C】本地原生法术可在演武堂升级，每级费用 `100×品质×当前等级`；默认原生1级，不擅自将玩家存档升满。没有转生系统，门槛替换为神仙20级＋原生法术10级。觉醒只选一个方向，材料不足整笔回滚。提升的是已拥有角色，未发放额外角色／资产。

### 9.2 法术进阶

【A】原表8项可进阶法术，最低10级、两项指定材料、增加生命百分比。包裹详情提供实际「进阶」操作。

【B/C】每本法术进阶一次，只有装备时加成；只消耗符合等级的未装备备用材料，绝不把目标本身或其他已装备法术当材料。自动选材料按等级、uid排序，失败事务不落盘。

### 9.3 助阵法术

【A】`cheer_skill_config` 为0–500级，效能从50%增加到100%；原界面将此百分比用于助阵法术格。消耗表按原 `object_type|id|level|count` 解释。

【B】正在助阵的神仙，其两项额外被动法术以该效能参与属性，再沿用八卦助阵转移；原生被动不折减。助阵者不在战场释放主动／特技。进阶生命加成同样折算。

【C】通过演武堂进修，等级绑定当前助阵神仙；原版绑定八卦法术阵位，本地这一存储简化明确不同。可单次批量兑换最多999个1206号材料（更高需求分批购买），消耗精确数量，满500级不再扣材料。

### 9.4 75项觉醒星宿

【A】5档品质×15种效果、每项10级：攻／防／命／法的百分比和固定值，法强百分比／固定值，暴击率、暴击伤害、抗暴率、暴击减伤、免死。完整数值见附录。免死表每场1次；与特技复活次数独立。

【C】本地在原生法术觉醒后可装备，每位最多5颗，同类不重复；演武堂提供兑换、装备、卸下、升级。没有星宿就不会获得其战斗效果。品质、逐级效果取原表，购买／升级银两和开放条件是本地规则。
