# 包裹模块逆向与实现

## 数据和素材

`inventory.py` 从 APK 1061 和本机已保存的1263更新缓存提取893条资料：44件武器、40件防具、25件法宝、64项法术、3类灵石，以及717项其他物品。物品与法术分别使用 `i<ID>`、`s<ID>` 键，避免相同数字ID冲突。

[包裹资源介绍表.xlsx](../outputs/inventory-20261021/包裹资源介绍表.xlsx) 有六个分类工作表及规则与来源表，包含原文简介、基础属性、成长、等级上限、原获取途径、本地功能和图集位置。[包裹逆向数据.json](../outputs/inventory-20261021/包裹逆向数据.json) 包含物品字段、原成长/消耗表和来源SHA-256。

主要依据为 `item_base.csv`、`item_name.csv`、`skill_base.csv`、`skill_name.csv`、`equip_enhance_cost.csv`、`stone_cost_worth.csv` 和原版 `ui/packageUI.lua`、`common/common_def.lua`。原 `getAllProps` 排除主类10、11、13、15；本地资源图录将这些附录资料保留在道具分类，并在表格“原包裹显示”列区分。

78份新增素材/脚本快照在 `inventory_resources/` 中，清单保留来源、实际长度、索引长度和SHA-256。全部893条资料均可定位到真实图标，不用其他物品图片替代。

截图物品对应：筋斗云4002，曼陀罗4012，定风珠4013，火眼金睛43，一气化三清42，魂缘丹1024，精魄石10000。1350是活动道具“定风珠”，不是法宝，也不是精魄石。法术配置可核对火眼金睛10级32.6%、一气化三清10级32.5%。截图中的装备高阶附加数值并非单纯基础强化，本地没有伪造其七阶/六阶等级或属性。

## 使用

首页底部“包裹”进入；左侧六类切换，右侧上下滑动，资源图录每页20项并可翻页。点击图标或名称查看完整介绍。底部导航保留，安卓返回按确认框、完整介绍、选择器、详情、包裹列表逐层返回。

- 旧存档初始为空包裹，银两、角色、经验、阵容和关卡不变。点击“领取入门包裹”后才能获得一次性体验物资。
- “资源图录”能查看全部资料，用银两兑换已接入玩法的物品。未接入者只展示资料，不出售、不消耗。
- 装备：选择任意已拥有神仙，支持替换、卸下、强化和镶嵌。列表显示佩戴者、等级、实际属性。
- 法术：第1格为不可替换、不可卸下的自带法术，第2、3格按位置装配，不限制主动／被动组合，同一神仙不可重复装备同名法术。
- 灵石：选择匹配的武器/防具/法宝灵石镶嵌，支持无损卸石；3颗同类同级合成1颗高一级灵石。
- 道具：小包子/包子恢复体力，经验类道具增加本地行者经验，魂缘丹培养所选神仙，精魄石兑换银两。同名装备碎片10合1。
- 熔炼：左侧“熔炼”筛选可熔炼装备/法术；点击物品在详情中确认。已穿戴、镶有灵石的物品不能熔炼。
- 阵容页显示实际装备及被动法术，点击槽位可进入包裹管理。角色面板和战斗使用装备后的实际属性。

## 原版与本地规则

名字、描述、图片、基础属性、成长、原等级上限、强化银两表和灵石属性百分比来自原资源。装备属性采用 `基础值 + upgrade_plus × (等级−1)`；被动法术按配置百分比增强攻防生命。

以下是明确的本地玩法，不能视为原服务器规则：

| 项目 | 本地实现 |
|---|---|
| 装备槽 | 每位神仙各1件武器、防具、法宝；自带法术固定，另外2格按位置装配 |
| 主动法术 | 原生及两个额外槽均参与配置概率判定，读取法术等级和威力成长；不覆盖自带技能，详见 [战斗规则](BATTLE.md) |
| 法术升级 | 100×星级×当前等级银两；原上限 |
| 灵石 | 每件装备1孔、3合1、最高10级、无银两合成费；卸石完整返还 |
| 灵石加成 | 当前装备属性×(1＋stone_cost_worth.base)，不放大整名角色的基础属性 |
| 碎片合成 | 10个同名装备碎片合成对应装备 |
| 魂缘丹 | 所选神仙升1级，最高20级 |
| 精魄石 | 熔炼产物；每颗兑换20银两 |
| 熔炼 | 产出max(1,星级)×等级颗精魄石，不返强化银两 |
| 图录兑换 | 物品max(40,星级×100)银两，法术最低100银两 |

64项法术均可按原装配规则进入额外格；大乘经的原配置强度及成长均为0，不伪造属性加成。原服活动、VIP、转生、精魄技能等道具所属系统仍未接入。礼包随机奖励、原服合成概率、装备进阶/重生、法术突破没有推测实现；原始配置保留在资料中。旅途掉落未增加，物资来源为主动领取、银两兑换、合成和熔炼。

## 存档与复现

包裹存放在原SQLite玩家state中的 `inventory` 字段，实例使用独立uid；同类同级灵石和道具堆叠，装备和法术保持独立实例。所有扣费、材料消耗、产出和属性变更使用同一 `BEGIN IMMEDIATE` 事务及已有请求幂等键；重复请求不会重复扣费或领取。

原2015 JSON解码器无法处理空数组，客户端在解析前仅对字符串外的空数组token转换为空表，不改动物品描述文字。

重新提取和构建：

```sh
python3 scripts/export_inventory_report.py
python3 scripts/build_local_game.py
.runtime/venv/bin/python -m unittest discover -s tests -p 'test_*.py'
```

Excel构建器是 `scripts/build_inventory_workbook.mjs`，依赖 `@oai/artifact-tool`。正常APK构建不需要连接原渠道客户端。`snapshot_inventory_resources.py` 仅在需要重新采集本机原版缓存时使用，不读取账号或存档。
