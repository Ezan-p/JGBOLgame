# 金箍棒本地可玩版

这是在原 APK 的 ARM32 Cocos2d-x 引擎中运行的独立本地模式。使用原包中的场景、角色立绘、角色基础属性与关卡名称；重新实现本地界面、战斗、奖励和存档。**它不是原官服的完整复刻，也不接入原服账号。**

当前提供：

- 包裹按参考图还原六类导航与列表，解析893条资料，支持装备、强化、法术升级、灵石镶嵌/合成、道具使用和熔炼。详见 [包裹逆向与本地规则](INVENTORY.md)。

- 无需手机号或账号，自动创建并读取同一份本地存档。
- 初始伙伴孙悟空、沙悟净；原版图鉴的 **166 位神仙全部可招募**（5星46位、4星66位、3星35位、2星19位），包含更新版的元始天尊、如来佛祖。已拥有者自动从招募列表移除。
- “召唤”按原版 `summonUI.lua` 还原三栏卡片、左侧喜讯、免费倒计时、星级区间和结果展示；结果页采用原版居中大立绘、属性条、名称/星级、仙缘与“详情/继续”按钮。重复神仙按原版 `cortege_quality.csv` 获得 4/9/12/15 魂魄，左侧面板显示本次获得与共有数量。详见 [召唤逆向与本地规则](SUMMON.md)。
- 招募页面支持品质筛选、上一页/下一页，卡片显示阵营和原生技能名称。
- 神仙模块按原版 `ui/lineupUI.lua` 还原四张卷轴侧栏（神仙、魂魄、精魄、五法界魂）与“图鉴”按钮：神仙列出已拥有伙伴，魂魄只列数量>0的神仙魂魄并支持幻魂，精魄展示38项 ext_skill，五法界魂展示10项界魂并可按同阵营/同品质转化。点击图鉴才进入原版 `handbookUI` 四类图鉴（神仙、装备、法术、精魄），未拥有图标变暗、已拥有保持原色。神仙、魂魄共用 formationUI 详情页。完整依据见 [神仙模块逆向说明](CORTEGE.md)。
- 四类图鉴包含166位神仙、109件装备、64项法术和38项精魄；图鉴保持资料查阅；装备与法术的持有、装备和成长在包裹中操作。
- 阵容使用原版角色面板、十字布阵与更换列表；支持拖动换位、直接替换和自动保存。最多四名角色出战，角色培养至 20 级。详见 [阵容逆向说明](LINEUP.md)。
- 神仙详情底部“培养”打开原版 `trainingUI` 风格页面：四行成长条、元宝/蟠桃、培养/10次/精心培养/精心培养10次、剩余潜能点和本次培养结果。普通 5 蟠桃/次、精心 1 元宝/次；潜能耗尽时从其他属性转移。详见 [培养模块逆向说明](TRAINING.md)。
- 两章、十个关卡，依次解锁，已通关关卡可重复挑战。
- 旅途还原原版连续大地图与横向小关面板，可查阅67个大关、597个小关的敌人与奖励，已有十关接通本地挑战；详见 [旅途逆向说明](JOURNEY.md)。
- 服务端计算回合战斗；客户端使用原版四站位、血槽、书法墨迹与 CCBI 播放突进、技能、受击、死亡和结算，支持暂停、跳过、重放。参见 [战斗逆向说明](BATTLE.md)。
- SQLite 持久化；重复请求只结算一次，断线后可重试。

原客户端的公会、竞技场、原服剧情流程和充值未接入。装备与技能成长已提供明确的本地规则。原服账户或角色不能导入本地版。战斗页面已接入原版音乐及技能音效，可以在左下角关闭。

## 启动与操作

默认 `game.json` 已选择本地版。双击上一级目录的 `启动游戏台.command`，打开 <http://127.0.0.1:8766>，点击“启动游戏”和“连接画面”。

也可在 `cloud_android` 目录执行：

```sh
python3 manage.py start
python3 manage.py launch
```

首页使用原版仙山场景及按钮。“旅途”进入取经关卡；底部“神仙”打开神仙图鉴，点击头像查看详情，已拥有伙伴可培养或调整出战，未拥有者需通过“召唤”获取。左侧“我的神仙”只显示已拥有伙伴。“阵容”管理出战伙伴，点击立绘、顶部当前头像或仙缘/属性条打开同一详情页，底部“培养/传承”可用；图鉴未拥有神仙只显示初始属性与居中的返回。“召唤”打开按品质筛选的召唤列表。图鉴详情的关闭按钮或安卓返回键先返回列表，再次关闭回到仙山；底部导航也可切换页面。所有操作自动保存，没有真实货币支付。

每场战斗消耗 2 点体力；体力上限 60，每五分钟恢复一点。首通银两翻倍，失败获得 20 银两。培养费用为 `80 × 当前等级`。角色获取统一通过“召唤”，不再提供银两直接招募。

本地属性成长为 `原基础属性 × (1 + 0.14 × (等级 - 1))`。普通攻击伤害为 `max(1, round(攻击 - 0.45 × 防御))`；每第三回合攻击系数为 1.45。玩家队伍先行动，最多 30 回合。这些是本地规则，不代表原服务器的公式。

原生主动技能已按原配置的单体／群体分类接入本地战斗与原素材演出；包裹内已装备的攻防生命被动法术参与战斗，仙缘、法力和转生仍未接入。群攻次目标系数为主目标的 .55，治疗6恢复攻击的 .8，均为本地规则。角色获取不再设银两直购，统一使用召唤；最多四人出战，拥有角色数量没有这个限制。

## 返回原渠道版

在 `cloud_android` 目录执行：

```sh
python3 manage.py stop
cp .runtime/local_game/channel-game.json game.json
python3 manage.py start
python3 manage.py launch
```

原渠道版仍需其账号和原服务器。此操作保留本地 APK 与本地存档。

## 常见问题

- 显示“本地服务未响应”：先运行 `manage.py start`，确认 8770 端口服务存在，再点“重试连接”。待结算操作会复用原请求编号，不重复扣费。
- APK 与服务密钥不匹配：保留存档，使用同一个 `client-key` 重新构建、覆盖安装本地 APK。
- 角色画面变回渠道登录：检查 `game.json` 的包名是否为 `com.sygame.jingubang.localg`，且 `local_game` 为 `true`。
- 删除或覆盖 `.runtime` 会影响存档；单纯关闭网页或正常停止服务不会清除进度。
