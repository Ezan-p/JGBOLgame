# 旅途模块逆向与还原

## 数据与依据

从 APK 1061 与本项目保存的更新资源1263提取 **67个大关、597个小关**，包括普通关463个、精英关67个、首领关67个。第一章5关；29章各8关，10章各9关，27章各10关。

大关来自 `csv_config/map_name.csv`、`map_config.csv`；小关来自 `tollgate_name.csv`、`tollgate_config.csv`。人物采用各章 `cortege_base_*.csv` 中敌方阵容第一位的原始立绘。物品、法术名称与图标来自原始配置及图集。

构建输出 `.runtime/local_game/journey.json` 包含完整章节、前后关关联、体力、等级限制、经验、银两、每日上限、敌方阵容、概率奖励、三星奖励、首通配置、素材路径和来源SHA-256。`journey.py` 可重复提取，构建时校验依赖。

本次导出副本：[旅途关卡数据.json](../outputs/journey-20261020/旅途关卡数据.json)。

## 地图与小关设计

大地图使用 `map/1.jpg` 至 `map/12.jpg` 共12张800×576的连续绘画。山脉、寺庙、地府与云层已绘在底图中，无需重画。原 `background/world_map.lua` 提供64组节点坐标，坐标与字节码摘要保存在 `journey_layout.json`。

适配960×540画布后，每块地图宽750，节点位置为 `x×1200, y×540`，牌匾在节点下方约0.09屏高。绿牌表示整章完成，红牌表示当前推进章，灰牌表示后续章节；颜色读取实际本地进度。后续章节允许预览。

小关面板依据 `ui/subLevelUI.lua` 重建：宽95%屏幕、高80%，中心在50%／56%。上半部显示场景、属性、概率奖励、三星奖励及敌人立绘，下半部为横向拖动卡片。普通、精英、首领分别使用 `char_bkg.png`、红色 `BOSS_bkg2.png`、紫色 `BOSS_bkg.png`；人物裁剪读取原配置 `offset_x/offset_y`。奖励可点开原文说明。

原版通关星数 `pass_star` 由服务器返回，不能由“曾胜利”推断。本地存档没有星数，已胜利卡片显示“已通关”，不伪造三星。

## 使用

- 首页“旅途”进入大地图，左右拖动或点击左右箭头浏览。
- 点大关进入小关面板，左右拖动并点击卡片切换关卡。
- “关卡目录”可访问全部67章。第65–67章没有已核实的原包地图坐标，仅通过目录进入，不补造位置。
- 缺失的小关场景按原引擎规则回退到同章前一张可用场景，再回退到 `map/1/1.jpg`；第65–67章当前使用该默认场景，其关卡名称、人物和奖励仍取真实配置。
- 目录第3页包含44、46、54章，便于核对参考图。
- 关闭或安卓返回：奖励详情／挑战确认 → 小关面板 → 大地图 → 首页。
- 保留原版底部导航。

## 本地战斗边界

此次还原完整旅途资料与界面。已有两章十个本地战斗继续按存档ID 1–10结算，用 `original_id` 映射到原关卡；其余小关显示“关卡预览”。不改写现有角色、银两及进度。

上半部标明“原版关卡资料”。已解锁的小关点击“开战”后，显示真实本地消耗及收益：2体力、本地经验与银两、首通银两翻倍。原版道具掉落、三星判定、每日次数、扫荡与整章奖励尚未接入结算。

新资料打包为原生Lua表，以避开原JSON解码器无法处理空数组的问题；横向列表使用 `CCScrollView`，补偿旧引擎对父节点缩放的裁剪问题。
